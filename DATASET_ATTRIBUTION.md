# Dataset Attribution

This project uses the PTB-XL ECG dataset, version 1.0.3.

Original dataset:
Wagner, P., Strodthoff, N., Bousseljot, R., Samek, W., & Schaeffter, T. (2022).
PTB-XL, a large publicly available electrocardiography dataset (version 1.0.3).
PhysioNet. https://doi.org/10.13026/kfzx-aw45

Original publication:
Wagner, P., Strodthoff, N., Bousseljot, R., Kreiseler, F. I., Samek, W., & Schaeffter, T. (2020).
PTB-XL: A Large Publicly Available ECG Dataset.
Scientific Data. https://doi.org/10.1038/s41597-020-0495-6

Dataset license:
Creative Commons Attribution 4.0 International (CC BY 4.0).
https://creativecommons.org/licenses/by/4.0/

Source:
https://physionet.org/content/ptb-xl/1.0.3/

The processed arrays and labels in this repository are derived from PTB-XL
and have been modified through project-specific preprocessing and label
selection. They should not be confused with the original, unmodified dataset.
